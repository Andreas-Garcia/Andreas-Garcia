# Agents working in this directory

Before generating or editing a `cv.md` or `motivation_letter.md` under `Jobs/*/`:

1. Read `cv_format_spec.md` — format, structure, and process rules, including that job experiences/bullets must be selected by relevance to the job description.
2. Read `emphasis_priorities.md` — current non-format instructions on which projects/experiences to foreground. **Precedence:** JD relevance (step 1) decides *whether and how much* to say about a project; emphasis_priorities.md only breaks ties among content already relevant to the JD — it never justifies adding project details (e.g. a whole tech stack) the JD didn't ask for.
3. Use root `README.md` as the source of truth for facts (experiences, projects, metrics).
