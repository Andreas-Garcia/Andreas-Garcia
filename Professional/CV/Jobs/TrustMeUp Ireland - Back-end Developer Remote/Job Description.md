## About TrustMeUp

TrustMeUp is a social impact platform that offers technological solutions for various fundraising challenges nonprofits have. It provides an innovative loyalty solution with commercial perks for donors and an all-in-one management platform for nonprofits. It also offers APIs for merchants to connect to donate by shopping and similar functionalities.

## Description

This is a remote position.

You are going to work in an open-minded, outcome-oriented and helpful team. As a back-end developer, you will need to work with front-end developers as well as other API consumers like plugin developers regularly, so being a good communicator and collaborator is an important aspect for this role. You are also expected to attend pre-scheduled online meetings. You'll also take a part on estimating future tasks and be responsible to deliver on the defined time frame.

## Requirements

### Qualifications

As a Back-end Developer at TrustMeUp, you will:

- Design and develop API & operational services.
- Identify and fix bugs.
- Write efficient code, find and fix bottlenecks.
- Write unit tests.
- Work with Dev-ops, front-end or plugin developers to maintain services & new features.
- Write documentation & run technical analysis if required.

A good understanding of:

- Python
- Django
- GraphQL and/or REST API's.
- Relational databases.

Nice to have:

- Experience with AWS services (Managed Blockchain would be an advantage).
- Experience with online payment services.
