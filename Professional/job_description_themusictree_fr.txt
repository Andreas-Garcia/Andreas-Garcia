🚀 PROJETS DÉVELOPPÉS :

	🎧 HearTheMusicTree : Gestionnaire bibliothèque musicale cloud avec playlists intelligentes

	🃏 The Music Deck : Jeu de cartes collectionnables musical avec stratégie de combat basée sur les genres (Expo, React Native, TypeScript, Node.js, NestJS)
