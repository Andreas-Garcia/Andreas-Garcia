# Agents working in this repo

This is Andreas Garcia's personal portfolio/CV repo, not a software product.

- **CV and motivation letter generation:** see `Professional/CV/AGENTS.md` — it points to the format spec, current emphasis priorities, and the facts source (`README.md`).
- **`README.md`** (repo root) is Andreas's GitHub profile README — it's also the single source of truth for facts about experience, projects, and metrics used in CVs/letters, but that's not its primary purpose.
- **Stats/badges generation (`languages-stats.svg`, `streak-stats.svg`, etc.):** see `scripts/` and `SELF_HOST_STREAK_STATS.md`.
- **Interview prep simulations:** `Professional/interview_prep.md`.
- **macOS maintenance scripts (unrelated to the portfolio):** `scripts/free-cache-macos.sh`, `scripts/docker-unstick-macos.sh` (installed as `~/.local/bin/docker-unstick`; `--check` mode runs every 2 min via `com.andreas.docker-stuck-check.plist`, symlinked into `~/Library/LaunchAgents/`).
