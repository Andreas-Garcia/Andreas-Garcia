## Our technology

- **Server-side:** Python. Most websites powered by Django and Django-REST-framework. Pandas, Numpy and Jupyter for analysis and forecasting, plus Celery, RabbitMQ, SQS and Airflow for background processing.
- **Infrastructure:** AWS heavily, most of the "Hashistack" (e.g. Packer, Consul, Terraform) as part of a continuous deployment pipeline.
- **Client-side:** React, Redux and SASS; mobile apps with native code or React Native.
