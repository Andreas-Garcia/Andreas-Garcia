# Open Source Contributor (Remote)

**Employment Type:** Independent Contractor (Hourly)  
**Location:** Remote  
**Compensation:** $50 – $85 per hour  

## Role Overview

We are seeking experienced developers with a strong record of open-source contributions to join a global network of engineers supporting projects in AI, data systems, and enterprise software infrastructure.

This role is ideal for developers who are actively involved in the open-source ecosystem and enjoy building scalable backend systems, writing clean code, and contributing to high-quality engineering initiatives.

## Key Responsibilities

- Design challenging coding problems with clearly defined input/output specifications, constraints, and function signatures
- Develop complete mini-repositories including:
  - Problem statements
  - Reference solutions
  - Comprehensive unit tests (10–20 test cases)
  - Executable test runners
- Write clean, production-quality code aligned with strict test expectations
- Develop high-coverage test suites covering edge cases, invalid inputs, and performance constraints
- Ensure full executability with no missing dependencies, configuration issues, or signature mismatches
- Follow best practices for version control and collaborative development

## Required Qualifications

- 3+ years of backend development experience
- Experience with one or more of the following languages: Rust, C++, C, COBOL, Java, Ruby, PHP, Python, TypeScript, Go, C#, JavaScript
- Strong understanding of clean code, modular design, and performance optimization
- Familiarity with Git-based collaboration including pull requests, code reviews, and issue tracking
- Experience with Docker and basic CI/CD workflows such as GitHub Actions or similar tools

## Role Details

- **Time Commitment:** Approximately 10–20 hours per week
- **Work Type:** Fully remote with flexible working hours
- **Opportunity** to contribute to high-impact projects in AI, data, and enterprise software systems

## Contract & Engagement Details

- Independent contractor engagement
- Weekly payments based on completed work
- Projects may be extended, shortened, or concluded depending on project needs and performance
