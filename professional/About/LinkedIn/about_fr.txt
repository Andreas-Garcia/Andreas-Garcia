Réalisations et projets :

J'ai développé des outils, bibliothèques, plateformes et services dans divers contextes :

- BehindTheMusicTree (Fondateur et Développeur Principal) :
  - AudioMeta Python : bibliothèque de métadonnées audio, 1500+ tests, 10 000+ téléchargements
  - GrowTheMusicTree : plateforme communautaire de classification de genres musicaux (Next.js, TypeScript, React)
  - TheMusicTreeAPI : API REST pour l'accès à la hiérarchie des genres et aux métadonnées (Django REST Framework, PostgreSQL)
  - HearTheMusicTree : gestionnaire de bibliothèque musicale cloud
- OpenSILEX (INRAE) : système d'information open-source pour les données FAIR (Java Spring Boot, RDF4J), services API REST backend et frontend (PHP, JavaScript)
