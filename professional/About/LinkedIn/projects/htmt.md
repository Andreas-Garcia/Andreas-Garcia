# HearTheMusicTree

## Nom du projet*
HearTheMusicTree

## Descr (<2000 char)
Gestionnaire de bibliothèque musicale cloud pour collectionneurs, DJs et amateurs qui veulent garder la main sur leurs fichiers. S’appuie sur AudioMeta Python pour les métadonnées. Fonctionnalités : playlists intelligentes (style, sous‑genre, époque), support multi‑formats et multi‑tags, stockage cloud sécurisé, connexion Spotify / Google (OAuth), empreinte audio et enrichissement MusicBrainz. Backend Django REST Framework, PostgreSQL. Déploiement Docker et CI/CD (GitHub Actions).

## 5 skills
- Django REST Framework
- PostgreSQL
- Python (AudioMeta, APIs)
- Docker / CI-CD (GitHub Actions)
- APIs externes (Spotify, MusicBrainz)
