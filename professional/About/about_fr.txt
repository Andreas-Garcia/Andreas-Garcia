**Réalisations et projets :**

J'ai développé des outils, bibliothèques, plateformes et services dans différents contextes :

- **TheMusicTree** (Fondateur & Lead Developer) :
  - **AudioMeta Python** : bibliothèque métadonnées audio, 1500+ tests, 20k+ téléchargements
  - **GrowTheMusicTree** : plateforme communautaire de classification de genres musicaux (Next.js, TypeScript, React)
  - **TheMusicTreeAPI** : API REST pour l'accès à la hiérarchie de genres et métadonnées (Django REST Framework, PostgreSQL)
  - **HearTheMusicTree** : gestionnaire bibliothèque musicale cloud
- **OpenSILEX** (INRAE) : système d'information open-source données FAIR (Java Spring Boot, RDF4J), backend API REST et frontend (PHP, JavaScript)
